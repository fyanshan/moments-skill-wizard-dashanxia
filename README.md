# 朋友圈 Skill 生成向导 · 使用说明

> 给**完全不懂技术**的人：装好这个 skill，跟 AI 说一句话，它就带你走完 5 步，最后生成一个**完全属于你、语气像你本人**的朋友圈写作助手。以后写朋友圈，一句话唤起就行。

## 这个 skill 能帮你解决什么
你每次让 AI 写朋友圈，都得重新教它认识你——语气不对、经历说错、一股 AI 味。这个向导把"教 AI 认识你"这件事，变成一次走完、永久复用的流程。

## 包里有什么
- `SKILL.md` —— 向导本体，AI 按它一步步带你走
- `references/persona-template.md` —— 人设底稿填空模板（第 1 步发给你填，不会写也有底）
- `references/skill-usage-template.md` —— 生成 skill 时自动套用的使用说明模板
- `references/团队skill制作指南·人话版.md` —— 想搞懂"为什么这么做"就看这份

## 安装步骤（一次即可）
1. 打开 WorkBuddy → 技能管理 → **从链接导入**。
2. 粘贴本仓库地址：`https://github.com/fyanshan/moments-skill-wizard-dashanxia`
3. WorkBuddy 自动拉取并安装。
4. 在对话里说：**「帮我做我的朋友圈 skill」**，向导就开始带你走。

> 本仓库为**公开仓库**，任何人粘贴上面的链接即可一键导入，**无需注册 GitHub 账号、无需被添加为协作者**。

## 走完 5 步你会得到什么
1. 一份你的人设底稿（你填的模板，存成文件）
2. 一组你挑中的对标朋友圈（逸芳 / 导师真实样本）
3. 一条你愿意发的定稿朋友圈
4. **一个以你命名的 skill**（如 `你的名字-moments`），里面含：
   - `SKILL.md`（你的声音指纹 + 改写流程）
   - `references/`（底稿 + 对标样本）
   - **`使用说明.md`**（这份说明的同款，你打开就会用）
5. 以后写朋友圈：「用我的朋友圈 skill 写一条关于 XX 的」即可，前 4 步都不用再走。

## 给使用者的提醒
- 你的底稿、对标样本都只存在**你自己的 skill** 里，不外传。
- 生成的 skill 文件夹默认存在你本机 `~/.workbuddy/skills/`，就是你的工具包，无需分享即可自用。
- 这是辅助工具，最终发出去前你过一眼最稳。
