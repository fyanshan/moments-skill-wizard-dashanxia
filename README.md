# 朋友圈 Skill 生成向导（开源免费版）

> 一个免费的 AI 向导：带你走完 5 步，最后生成一个**完全属于你、语气像你本人**的朋友圈 / 内容写作 skill。不要钱，装好就能用。

## 它能帮你做什么
你每次让 AI 写朋友圈，都得重新教它认识你——语气不对、经历说错、一股 AI 味。这个向导把「教 AI 认识你」变成一次走完、永久复用的流程。以后写朋友圈，一句话唤起。

## 包里有什么
- `SKILL.md` —— 向导本体，AI 按它一步步带你走
- `references/persona-template.md` —— 人设底稿填空模板（第 1 步发给你填，不会写也有底）
- `references/skill-usage-template.md` —— 生成 skill 时自动套用的使用说明模板
- `references/团队skill制作指南·人话版.md` —— 想搞懂"为什么这么做"就看这份

## 安装（一次，约 2 分钟，无需付费）

**方式一（推荐，不用命令行）：**
1. 打开 WorkBuddy → 技能管理 → **从链接导入**
2. 粘贴本仓库地址：`https://github.com/fyanshan/moments-skill-wizard-dashanxia`
3. WorkBuddy 自动拉取并安装
4. 在对话里说：**「帮我做我的朋友圈 skill」**，向导就开始带你走

**方式二（手动）：**
```bash
git clone https://github.com/fyanshan/moments-skill-wizard-dashanxia.git ~/.workbuddy/skills/moments-skill-wizard
```
或下载本仓库 ZIP，解压后把文件夹放到 `~/.workbuddy/skills/moments-skill-wizard/`
（Windows：`C:\Users\你的用户名\.workbuddy\skills\moments-skill-wizard\`）

> 找不到 `.workbuddy` 文件夹？它是隐藏文件夹。
> - macOS：在 Finder 按 `Shift + Command + .` 显示隐藏文件，再把文件夹拖进去。
> - Windows：在资源管理器地址栏直接粘贴上面的路径，回车即可进入。

## 走完 5 步你会得到什么
1. 一份你的人设底稿（你填的模板，存成文件）
2. 一组你挑中的对标朋友圈（你凭感觉挑的真实样本）
3. 一条你愿意发的定稿朋友圈
4. **一个以你命名的 skill**（如 `你的名字-moments`），里面含：
   - `SKILL.md`（你的声音指纹 + 改写流程）
   - `references/`（底稿 + 对标样本）
   - **`使用说明.md`**（你打开就会用）
5. 以后写朋友圈：「用我的朋友圈 skill 写一条关于 XX 的」即可，前 4 步都不用再走。
